# Cover Contract

Ask the creator for `cover.png` first. It must be PNG, exactly 16:9, and at
least 640×360. Copy the accepted file to `dist/cover.png` after validation.

If the creator requests a generated cover, use the technical artist's approved
art direction. Do not use external URLs or place the resulting product cover in
the game ZIP. If the game needs a related in-game image, create a separate local
asset under `assets/`.
