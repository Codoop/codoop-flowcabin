# Game Card and Quality Gate

Record: player fantasy, player goal, core loop, desktop mouse/keyboard controls,
feedback, how a round ends or continues, initial session length, persistence,
visual direction, playtest tasks/results, and this round's change hypothesis.

The first playable version must have a visible goal, immediate feedback, a
recoverable failure/retry or continued-progress path, readable primary controls
in a desktop panel, an understandable pause/resume state, and an authored visual
identity. It must be followed by an invited creator playtest, not merely a link.
