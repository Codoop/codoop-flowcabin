# Expert Orchestration

Always read `skills/_shared/game-designer.md` and
`skills/_shared/technical-artist.md` before the first playable build. Record
each conclusion and approval in `design-notes.md`.

Read `level-designer.md` for maps, rooms, routes, waves, operating cycles, or
difficulty progression. Read `narrative-designer.md` for characters, story,
dialogue, missions, or choices. Read `audio-designer.md` whenever sound is used
or requested.

After feedback, start with the game designer, then reload only experts whose
domain changes. Before packaging, re-read every triggered expert. Each must have
an explicit final approval in `dist/validation-report.md`; otherwise packaging
is blocked.
