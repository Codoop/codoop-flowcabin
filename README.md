# codoop-game

Create offline, resumable H5 games for Codoop from a plain-language idea.

`codoop-game` guides a creator through a playable preview, validates the offline
game package, and produces `dist/game.zip` plus a separate `dist/cover.png`.

## Status

Initial implementation. Desktop-webview verification is intentionally deferred;
the included preview harness is the v1 compatibility test surface.
